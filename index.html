04 / Journey

How I'm learning.

A simple loop I repeat for every change on this site.

  1. Step 1

    Create a branch

    Every idea starts on its own branch, so the main site stays safe.

  2. Step 2

    Make small commits

    Short, clearly named changes that are easy to review.

  3. Step 3

    Open a pull request

    Describe the change and ask for feedback before it goes live.

  4. Step 4

    Review and merge

    Fix comments, merge, and let GitHub Pages publish the update.
